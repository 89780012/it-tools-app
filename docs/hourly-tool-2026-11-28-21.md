## 工具与用途

- 名称：ISO 周日期转换器（ISO Week Date Converter）。
- 路由：`/tools/iso-week-calculator`；中文：`/zh/tools/iso-week-calculator`。
- 初始 worktree 干净，没有未完成新增工具。已阅读 CLAUDE.md、README.md、工具配置、最近 Git 更新及上一时段记录。现有时间戳、日期间隔、Cron 工具不提供 ISO 周日期双向转换，本次仅新增这一工具。
- 面向周报、排期和跨年周编号核对，转换公历日期与 `YYYY-Www-D` 周日期。例如 `2021-01-01` 对应 `2020-W53-5`，而 `2018-12-31` 对应 `2019-W01-1`。
- 显示公历日期、ISO 周日期、周所属年份、周编号、星期、本周周一与周日、该 ISO 年的总周数。提供双向示例、清空、回车转换、复制与 `iso-week.txt` 下载。

## 实现与范围

- `src/lib/iso-week.ts` 提供纯函数，复用已有 `parseCalendarDay` 严格验证公历日期，不允许日期自动溢出。使用 UTC 日序号避免本地时间、时区及夏令时影响，并用 `setUTCFullYear` 避免 0001–0099 年映射至 20 世纪。
- ISO 周从周一开始，第 1 周包含 1 月 4 日，周所属年份取该周周四所在年份。每个 ISO 年有 52 或 53 周，逆向转换验证第 53 周是否真实存在。
- 公历输入使用 `YYYY-MM-DD`，周日期使用 `YYYY-Www-D`（大写 W、两位周编号、星期 1–7）。年份为 0001–9999，允许外部空白，原始输入最长 64 个 UTF-16 单元。不接受时间戳、年份 0、宽松日期、地区周历或财务周历。
- 逆向转换后的公历日期也必须在 0001–9999 年内。因此 `9999-W52-6` 和 `9999-W52-7` 明确报范围错误。有效日期 `9999-12-31` 的周日范围端点仍展示为 ISO 扩展年份格式 `+010000-01-02`；页面已解释这一边界。
- 编辑输入、切换方向、加载示例或清空，立即移除旧结果与反馈。切换方向同时清空输入，清空按钮保留当前方向。错误关联输入并移焦，结果区域提供可访问性更新通知。
- 复用 Workbench、Panel、Field、Input、Button、Output 和 Vite 页面发现机制。新增时间分类条目、搜索别名及相关工具，补齐全部 12 种语言的界面、星期、错误与 SEO 元数据。
- 阿拉伯语摘要用 Unicode LRI/PDI 隔离结果值，避免日期中的数字段受双向文本规则影响而倒序。这些方向控制字符也保留在复制和下载的人类可读摘要中；公历及 ISO 周日期输入仍为纯文本、从左到右显示。
- README.md 和 CLAUDE.md 更新至 85 个工具（含隐藏工具）、1044 个预渲染页面。不引入依赖、账号、外部 API 或后台服务。
