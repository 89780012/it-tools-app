# IPv4 CIDR 聚合器（2026-11-28 18 时，Asia/Shanghai）

## 工具与用途

- 英文路由：`/tools/ipv4-cidr-aggregator`；中文路由：`/zh/tools/ipv4-cidr-aggregator`。
- 起始 worktree 干净，没有未完成的新工具。已阅读 CLAUDE.md、README、相关模块规范、工具目录、近期 Git 更新和时段记录，以及 `docs/api-network-deployment.md`。
- 现有子网计算器处理单个网段；本工具用于整理防火墙、路由和访问白名单中的多个 IPv4 地址与 CIDR，仅新增这一工具。
- 每行输入一个地址或 CIDR，跳过空行，清除主机位，移除重复及被覆盖的网段，将相邻范围分解为最少的精确 CIDR 列表。不会为了缩短列表而填补地址范围之间的空隙。
- 提供示例、清空、结果统计、复制和 `aggregated-ipv4-cidrs.txt` 下载。复制与下载仅包含每行一个的 CIDR。修改输入立即清除旧结果和错误。统计显示输入条目数、输出 CIDR 数、唯一地址数和被清除主机位的输入条目数。

## 输入规则与实现

- 接受十进制 IPv4 地址和 /0–/32；无前缀地址视为 /32。拒绝八位段和前缀的前导零、IPv6、注释、范围、逗号分隔、内部空格及非十进制语法。
- 支持 LF、CRLF、CR，允许整行首尾空白。错误行号包含空行，从 1 开始；错误与输入字段关联，并将焦点移回输入。
- 最多 10,000 个非空条目、500,000 个 UTF-16 代码单元。全部输入验证成功后才显示结果，不跳过非法行。
- `192.0.2.10/24` 代表整个 `192.0.2.0/24`，页面明确提示主机位处理规则。地址计数包含网络地址、广播地址和保留地址，不代表可用主机数。
- 核心纯函数位于 `src/lib/ipv4-cidr-aggregator.ts`：将网段转换为整数区间，排序并合并重叠和相邻区间，再从各区间起点逐段选择最大的对齐 CIDR。使用精确的 Number 算术，值不超过 2^32，避免有符号 32 位位运算，不逐地址展开，/0 也能直接处理。
- 复用 Workbench、Panel、Field、Textarea、Button 和 Output；本工具的输入及结果框采用可滚动的固定字段尺寸，避免大量行文本触发自动增高布局。
- 按现有 Vite 页面发现方式增加页面，登记工具分类、搜索别名和相关工具。新增全部 12 种语言的名称、描述、SEO、界面和错误文案，共享字典与 SEO 逻辑自动发现，无需改动通用 SEO 规则。
- README 和 CLAUDE.md 的统计更新为 82 个工具（含隐藏工具）、1008 个预渲染页面。没有新增依赖、外部 API 或后端服务。
