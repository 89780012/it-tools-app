# JSON 合并补丁（2026-11-28 14 时，Asia/Shanghai）

## 工具与用途

- 英文路由：`/tools/json-merge-patch`；中文路由：`/zh/tools/json-merge-patch`。
- 开始时 worktree 干净。已阅读 CLAUDE.md、README、现有工具目录、近期 Git 更新、最近工具记录和 `docs/api-network-deployment.md`。现有 77 个工具没有应用 RFC 7396 合并补丁的工具，本时段仅新增此工具。
- 用于合并环境配置、验证 API 的 JSON Merge Patch 请求、删除废弃字段。输入目标 JSON 和补丁 JSON，提供示例、清空、结果展示、复制和 `merged.json` 下载。

## 实现与规则

- `src/lib/json-merge-patch.ts` 按 RFC 7396 递归合并对象。对象成员值为 null 时删除字段；数组、字符串、数字、布尔和根级 null 补丁整体替换目标。向非对象应用对象补丁时从空对象开始。
- 空对象补丁保留目标对象的内容；向标量或数组应用空对象补丁产生空对象。补丁内数组的 null 元素保持原样。页面明确说明成员 null 不能用于赋值 null，以及 RFC 6902 操作数组不在此工具的解释范围内。
- 复用 `lossless-json`，保留超大整数、长小数、负零和指数数字的原始精度，不转成 JavaScript Number。输出统一为两空格缩进，原始格式和键顺序不保证保持。
- 使用无原型字典与自身字段枚举，安全保留 `__proto__`、`constructor`、`prototype` 等合法 JSON 键，不查找继承字段，不污染原型。
- 每个输入最多 500,000 个 UTF-16 代码单元、64 层嵌套；格式化输出最多 5,000,000 个代码单元。嵌套检查忽略字符串内括号和转义引号。空值、JSON 语法错误和大小超限均显示本地化反馈；两个输入都要有效后才返回完整结果。
- 使用严格 JSON 解析。现有解析器拒绝值冲突的重复键，相同值的重复键会被折叠；页面建议保持对象键唯一。
- 修改任一输入时清除旧结果和错误；输入校验失败聚焦对应字段，通过 `aria-invalid`、`aria-describedby` 和 alert 关联错误。复用 Workbench、Panel、Field、Textarea、Button、Output 和已有复制失败反馈。
- 登记 JSON 工具分类、搜索别名和相关工具；沿用 Vite 页面发现、React Router、字典自动合并与共享 SEO 规则。补充全部 12 种语言的工具名、描述、SEO、界面和错误文案，无新增依赖、API 或后端改动。
- README 和架构文档计数更新为 78 个工具（含隐藏的翻译工具）、960 个预渲染页面。
