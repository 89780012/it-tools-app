## 改动与行为

- `src/lib/json-key-sorter.ts`：纯函数递归排序所有对象的键，包括数组中的对象。提供升序/降序、2/4 空格缩进和紧凑输出。数组元素顺序保持不变，接受对象、数组及标量根值。
- 使用区分大小写的 UTF-16 单元比较，不使用语言相关排序；数字键按文本比较，因此升序时 `"10"` 在 `"2"` 前面。直接序列化成员，避免 JavaScript 对整数属性名的自动重排。
- 保留大整数、小数、指数和负零的数字写法；字符串和键重新进行 JSON 转义，不保留原来的转义形式。拒绝重复键，包含相同值的重复键和转义后相同的键；`__proto__`、`constructor` 等作为普通数据处理。本工具不执行 RFC 8785 规范化。
- 限制输入 500,000 个 UTF-16 单元、嵌套 64 个容器层级，输出 5,000,000 个单元；先检查深度再调用解析器，生成时累计输出预算。缩进输出超限时可切换紧凑格式重试。
- `src/components/tools/json-key-sorter.tsx`：复用 Workbench、Panel、Field、Textarea、Output 和错误组件，提供输入、显式排序、对象/键计数、结果展示、复制、`sorted.json` 下载、示例和清空。编辑输入或选项会移除旧结果、旧错误和复制反馈；清空恢复默认选项并聚焦输入。错误与输入通过 aria-invalid / aria-describedby 关联，失败时聚焦输入。
- 沿用 Vite 模块发现和 React Router 路由，更新 tools-config.ts、搜索别名及相关工具工作流。新增完整的 12 语言字典，含名称、描述、SEO、界面和错误文字；使用现有规则生成 canonical、12 条 hreflang 和站点地图。
- README.md、CLAUDE.md 同步为 90 个工具（含隐藏项），12 语言共 1104 个预渲染页面。
