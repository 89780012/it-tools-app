## 实现与规则

- `src/lib/border-radius.ts`：纯函数校验四角半径，按左上、右上、右下、左下的物理顺时针顺序生成 CSS；自动压缩为一至四值简写，水平与垂直半径不同时生成斜杠语法。
- 支持 px 和 %，非负普通十进制数、最多两位小数，接受 `.5` 写法并规范化前导零和两端空白。px 范围为 0–1000，% 范围为 0–100；拒绝负数、指数、逗号、CSS 单位、表达式、空值和超限数值，不静默截断或钳制。
- 四角默认使用相同的水平和垂直数值；启用“单独设置垂直半径”时从当前水平值复制一组，随后可独立编辑八个值。关闭后仅使用水平值；再次启用时重新复制当前水平值。
- 支持有机形状示例、50% 椭圆预设、实时预览、复制 CSS、下载 `border-radius.css` 和清空。清空会恢复 px、关闭独立垂直半径、清除输入/错误/结果、隐藏形状，并聚焦第一个输入框。
- 输入错误会显示本地化提示，并通过 aria-invalid / aria-describedby 关联具体轴与角；移除旧 CSS 和预览，修正后立即恢复。复制成功/失败均有反馈，结果变化时重置反馈。
- 预览最大为 320 × 180 CSS 像素，小屏幕上仅宽度收缩。预览的边框、颜色和尺寸不进入导出结果。只有校验后的数值和单位可进入预览样式。
- 页面说明水平百分比相对于宽度、垂直百分比相对于高度，重叠半径由浏览器按比例缩小，因此 50% 会在矩形上形成椭圆。切换单位保留数字，不执行换算。物理角顺序不随 RTL 改变。不支持导入 CSS。
