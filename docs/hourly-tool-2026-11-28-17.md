## 功能与实现

- 提供 NFC、NFD、NFKC、NFKD 四种形式，复用浏览器 `String.prototype.normalize` 实现 UAX #15 的分解、组合、组合类排序和组合排除规则。
- 输入文本后主动处理，展示完整结果和是否变化；支持示例、清空、复制及按形式命名的 UTF-8 文本下载，如 `normalized-nfkc.txt`。
- 对比处理前后的 Unicode 码点数、UTF-16 代码单元数、UTF-8 字节数，并分别预览前 64 个码点。预览截断不影响结果、复制和下载。码点数不等于可见字符数。
- 输入最多 100,000 个 UTF-16 代码单元，输出最多 1,000,000 个；兼容分解可能扩张文本，因此单独检查输出长度。保留输入空白，不改变大小写，不移除不可见字符。
- 拒绝空输入、超限输入、无效形式和未配对的 UTF-16 代理项，后者报告从 1 开始的代码单元位置，避免导出时被静默替换。仅含空白的文本允许处理。
- 编辑输入或切换形式时清除旧结果及错误；清空恢复 NFC。输入错误带 alert、字段关联和焦点定位。复用现有 Output 的复制失败提示与可选择结果。
- 提供四种形式的解释及兼容形式可能消除有意义区别的说明。使用浏览器内置的 Unicode 版本，不做大小写折叠或形似字符检测。
- 复用 Workbench、Panel、Field、Textarea、Button、Output 和现有 Vite/React Router 页面发现方式。添加工具目录登记、搜索别名及相关工具，补齐全部 12 种语言的界面、错误和 SEO 元数据。
- 新增翻译分组由现有字典加载器及 SEO 预渲染流程自动发现，无须修改共享 SEO 规则。README 和 CLAUDE.md 同步为 81 个工具（含隐藏翻译工具）及 996 个预渲染页面。
- 无新依赖、外部 API、账号或后台服务；输入仅保留在页面状态。
