## 实现与规则

- `src/lib/css-gradient.ts`：验证色标和角度，生成 `linear-gradient(...)` 值及可直接粘贴的 `background-image` 声明。保留色标顺序，不进行静默排序。
- 支持 2–8 个色标，各自具有原生颜色选择器、十六进制颜色文本、位置和不透明度。添加时复制最后一个色标，可删除任意色标，达到数量边界时禁用对应按钮。
- 角度为 −360–360 的整数，0° 向上、90° 向右。颜色接受 #RRGGBB，输出转为小写；位置和不透明度为 0–100 的整数。输入两端空白会被去除。不透明度低于 100% 时生成 rgba；0% 仍保留 RGB 通道。
- 色标位置必须非递减；相同位置允许产生硬切换。首尾色标不必位于 0% 或 100%。不支持小数、命名颜色、缩写十六进制、径向渐变或导入 CSS，界面给出适用范围。
- `src/components/tools/css-gradient-generator.tsx`：输入修改后即时验证、更新预览和 CSS，提供三色示例、复制、`gradient.css` 下载和清空。清空会移除结果和错误、保留两个空色标，并聚焦角度输入。
- 输入错误会移除旧 CSS 和渐变，显示本地化错误并通过 aria-invalid / aria-describedby 关联具体字段；修正后自动恢复。复制成功或失败均有反馈，CSS 改变时清除旧反馈。只允许验证后的数值和颜色进入预览样式。
- 棋盘格展示透明区域，仅属于预览，不进入导出的 CSS。
- 按现有 React Router / Vite 页面发现方式注册页面，更新 tools-config.ts、搜索别名和相关工具工作流。新增完整的 12 语言界面、错误和 SEO 字典，复用元数据规则生成 canonical、12 条 hreflang 和站点地图。
