# TOTP 动态验证码生成器（2026-11-28 16 时，Asia/Shanghai）

## 工具与用途

- 英文路由：`/tools/totp-generator`；中文路由：`/zh/tools/totp-generator`。
- 起始 worktree 干净。已阅读 CLAUDE.md、README、相关模块规范、工具目录、近期 Git 更新及上一时段记录，并检查 `docs/api-network-deployment.md`。目录已有 HMAC 和 JWT 工具，但缺少基于 Base32 密钥的 RFC 6238 TOTP 工具，本时段仅新增这一工具。
- 用于核对双因素认证配置、调试验证端和复现指定时间的验证码。在本地输入 Base32 密钥，选择 SHA-1、SHA-256 或 SHA-512、6 或 8 位，以及 1–300 秒周期，生成一次性验证码。
- 时间戳留空时使用设备时钟，生成后自动刷新验证码与倒计时；填写 Unix 秒数时使用固定时间。展示时间计数器及有效区间，起点包含、终点不包含，同时显示 UTC 与 Unix 秒数。实时模式依赖设备时钟准确，所有参数须与验证端匹配。
- 支持 RFC 6238 官方示例、清空、复制及 `totp-code.txt` 下载。复制和下载仅包含验证码，保留前导零。密钥默认掩码显示，仅保留在页面内存，不写入浏览器存储或结果文件。

## 实现与输入规则

- `src/lib/totp.ts` 为纯函数，复用已有 CryptoJS HMAC，实现 RFC 4226 动态截断及 RFC 6238 时间计数，T0 固定为 0。计数器编码为 8 字节大端整数，支持超过 32 位的时间计数器，不用位运算截断整个时间值。
- Base32 接受 ASCII 大小写字母、2–7、ASCII 空白及连字符分隔。支持省略填充；提供 `=` 时须为规范数量且仅位于末尾。拒绝非法长度、非零末尾未使用位、非 ASCII 字符及 otpauth URI。
- 密钥原始输入最多 1024 个 UTF-16 代码单元，包括分隔符；最多解码为 640 字节。先检查 ASCII 字符再转换大小写，避免 Unicode 大写映射误接收非 Base32 字符。
- 时间戳支持 0–253402300799 的整数秒（1970 年至 9999 年）。周期支持 1–300 秒的整数。页面接受十进制、首尾空白和前导零，拒绝负数、小数、科学计数法及十六进制；空时间戳与明确输入 `0` 分别表示实时和 Unix 纪元。
- 修改任一输入会清除旧结果、错误和刷新定时器；清空恢复默认 SHA-1、6 位、30 秒和实时模式。组件卸载时清理定时器，验证码变化时清除旧复制反馈。输入错误具有 alert、字段关联与焦点定位。
- 复用 Workbench、Panel、Field、Input、Button 和 Output，遵循现有 Vite 页面发现及 React Router 路由。添加目录登记、搜索别名和相关工具，补齐全部 12 种语言的界面、错误、名称、描述和 SEO 文案。
- 共享字典加载和 SEO 逻辑自动发现新增资源，无须修改通用 SEO 规则。README 和 CLAUDE.md 的目录统计同步为 80 个工具（含隐藏翻译工具）、984 个预渲染页面。
- 无新增依赖、外部 API、付费服务或后端服务。

## 测试内容

- 新增 54 项核心测试及 4 项页面测试，另有自动发现的新页面渲染检查。全部 RFC 6238 附录 B 的 18 组官方结果均覆盖，包括 SHA-1、SHA-256、SHA-512 和 20000000000 秒时间戳。
- 用独立的 Node `crypto.createHmac` 和独立 Base32 编码器核对 200 组固定随机种子的密钥、时间、算法、位数与周期组合；密钥长度覆盖短密钥及超过 HMAC 分组长度的密钥，同时验证 Base32 往返。
- 覆盖 Unix 纪元、周期前后、1 秒和 300 秒周期、超过 32 位的计数器、最大时间、前导零、规范和省略填充、ASCII 分隔符、Unicode 映射字符、长度限制及各类非法参数。
- 页面测试覆盖示例、清空、编辑后旧结果失效、错误字段焦点及可访问关联、实时跨周期刷新、固定时间不刷新和卸载清理。
