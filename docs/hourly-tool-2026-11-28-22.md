# 每小时工具开发记录：JSON Patch 应用器

任务时段：2026-11-28-22（Asia/Shanghai）

## 工具与用途

- 名称：JSON Patch 应用器（JSON Patch Applier）。
- 路由：`/tools/json-patch`；中文：`/zh/tools/json-patch`。
- 初始 worktree 干净，没有未完成的新增工具。已阅读 CLAUDE.md、README.md、工具目录、Git 最近八次更新、20/21 时段记录、各模块约定及 `docs/api-network-deployment.md`。现有 JSON Diff、JSON Pointer 与 JSON Merge Patch 不提供 RFC 6902 操作数组的执行功能，本次只新增这一工具。
- 适合在调试 HTTP PATCH 请求、变更配置或验证补丁前，在本地检查补丁的实际结果。支持按顺序执行 `add`、`remove`、`replace`、`move`、`copy`、`test`。
- 两个输入框分别接收目标 JSON 与补丁数组；提供包含六种操作的示例、应用、清空、结果复制及 `patched.json` 下载。编辑或加载示例立即清除旧结果与反馈。失败显示字段与操作序号，关联错误并聚焦对应输入；不显示部分结果。清空后聚焦目标输入。

## 实现与范围

- `src/lib/json-patch.ts` 提供纯函数。复用已有 `lossless-json` 依赖保留整数、小数、指数和负零的原始数值文本。没有新增依赖、API、账号或后台服务。
- 路径使用 RFC 6901 字符串表示：`~1` 解码为斜杠，`~0` 解码为波浪号，单次解码避免误处理 `~01`；空路径选择根，`/` 选择空键。不接受 URI 片段，不对百分号或 Unicode 做额外转换。
- 数组 `add` 为插入，`/-` 为末尾追加；其他数组索引必须是不带前导零的非负整数且存在。`move` 的目的索引按删除源值后的文档计算；禁止移动到自身后代。父节点必须存在，不自动创建。
- `copy` 深复制容器，不产生引用别名；允许把根复制到子节点且不会形成循环。使用空原型对象和自有属性查询，`__proto__`、`constructor` 等作为普通数据处理。
- `test` 使用递归 JSON 结构相等：对象键顺序不影响结果，数组顺序影响结果，类型必须匹配。数值按精确十进制值比较，`1` 等于 `1.00`、`0` 等于 `-0`；规范化有效数字并用 BigInt 计算指数，避免 IEEE-754 舍入、溢出及巨大十进制展开。
- 要求补丁为操作对象数组，操作名区分大小写，必需成员必须存在；RFC 规定的未知附加成员被忽略。目标与补丁中的重复键（包括相同值和转义后相同的键）均拒绝。
- 根可以是任意 JSON 值。删除根后允许用后续 `add` 重新设置根；若最终没有文档则报错，因为无法复制或下载一个不存在的 JSON 文档。
- 每份输入最多 500,000 个 UTF-16 单元，嵌套最多 64 层，最多 200 项操作，每条路径最多 4,096 个单元。每步在序列化前核算深度与两空格缩进后的结果长度，结果最多 2,000,000 个单元；累计遍历格式预算为 20,000,000 个单元，防止反复复制放大。页面说明这些限制，达到总处理量上限时有专门错误提示。
- 复用 Workbench、Panel、Field、Textarea、Button、Output 及 Vite 页面发现方式。在 JSON 分类登记工具并添加搜索别名、相关工具推荐。
- 补齐全部 12 种语言的界面、错误及 SEO 元数据。现有字典、SEO 和站点地图生成逻辑自动收录。README.md 与 CLAUDE.md 的工具数量更新为 86（含隐藏工具），预渲染页面总数为 1056。
