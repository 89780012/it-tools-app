## 工具与用途

- 名称：CSS 三次贝塞尔缓动编辑器（CSS Cubic Bézier Editor）。
- 路由：`/tools/css-cubic-bezier`；中文：`/zh/tools/css-cubic-bezier`。
- 初始 worktree 干净，没有未完成的新增工具。已阅读 CLAUDE.md、README.md、完整工具目录、最近八次 Git 更新、最近时段开发记录、模块规范及 `docs/api-network-deployment.md`。现有 CSS 格式化、clamp 生成及颜色工具均不提供缓动曲线设计，本次仅新增这一工具。
- 用于设计界面过渡与动画的速度变化。可输入两个控制点，或选择线性、平缓、缓入、缓出、缓入缓出、超出回落六种预设；生成曲线图后，用时间滑块查看真实输出进度。
- 输出 `transition-timing-function` 与 `animation-timing-function` 两条声明，可复制或下载 `cubic-bezier.css`。提供超出回落示例、清空及错误处理；编辑、换预设或加载示例立即移除旧结果与复制反馈。无效字段显示关联错误并获得焦点；清空后四个输入为空，焦点回到首个输入。

## 实现与范围

- `src/lib/cubic-bezier.ts` 提供控制点校验、预设、CSS 生成及时间采样纯函数；没有新增依赖、后台服务、付费 API 或外部账号。
- 固定起点为 `(0, 0)`、终点为 `(1, 1)`。X 坐标必须为 0–1；允许 X 控制点次序颠倒。编辑器将 Y 范围限制为 −5 至 5，允许预先反向及超出终点，不将进度裁剪到 0–100%。CSS 规范本身允许更大的 Y 范围，这里是编辑器的明确限制。
- 接受最多四位小数的普通十进制数，允许正负号及 `.5` 形式，去除两端空白；拒绝空值、指数、十六进制、逗号、单位、非有限值、过多小数位及越界值。每个输入最多 32 个字符。输出规范化前导零、尾零和负零。
- 采样时先通过二分法反解 `x(t)`，再计算 `y(t)`，避免把曲线参数直接当作经过时间。保持精确起止值；处理端点和中点的零导数。滑块步长为 0.001，即时间 0.1%；进度显示两位百分数小数。数值计算采用浏览器双精度浮点数。
- SVG 图显示实际三次曲线、两个控制点、控制线、线性参照虚线及时间游标。纵轴根据控制点范围调整，保留负进度和超出进度；不依赖自动播放动画。
- 声明可放入 CSS 规则；目标属性、持续时间及其他动画设置由使用者另行配置，页面有说明。
- 复用 Workbench、Panel、Field、Input、Button、Output 和 Vite 页面发现方式。登记前端分类、搜索别名及相关工具推荐；为全部 12 种语言补齐界面、错误和 SEO 元数据。
- 国际化合并及 SEO 生成逻辑自动收录新字典和页面，无需修改共享路由或 SEO 实现。README.md 与 CLAUDE.md 工具数更新为 87（包括隐藏项），预渲染页面总数为 1068。
