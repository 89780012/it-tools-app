# 语义化版本排序器（2026-11-28 12 时，Asia/Shanghai）

## 工具与用途

- 英文路由：`/tools/semver-sorter`；中文路由：`/zh/tools/semver-sorter`。
- 开始时 worktree 干净。阅读 CLAUDE.md、README、工具目录、近期 Git 更新、最近新增工具记录和 `docs/api-network-deployment.md`，确认现有 76 个工具没有 SemVer 排序功能；本时段只新增此工具。
- 整理 Git 发布标签、核对预发布顺序、从列表中查找最高稳定版。每行输入一个版本，选择升序或降序，可接受小写 `v` 前缀。
- 显示版本数量、最高版本、最低版本和最高稳定版；提供示例、清空、复制和 `sorted-versions.txt` 下载。列表全部是预发布版本时明确提示没有稳定版本。

## 实现与规则

- `src/lib/semver.ts` 实现 SemVer 2.0 解析和比较。要求完整的 `major.minor.patch`，拒绝核心数字和预发布数字标识的前导零、空标识、非法字符及版本范围表达式。
- 数字以十进制字符串长度和字符比较，不转为 JavaScript Number，因此超过安全整数范围的版本号和预发布数字不丢失精度。
- 预发布版本低于对应的稳定版；数字标识低于非数字标识，非数字按 ASCII 大小写顺序比较。构建元数据不影响排序。同优先级和重复版本保持输入顺序，输出保留原始标签及构建元数据。
- 最多 10,000 个非空版本行、500,000 个 UTF-16 代码单元。支持 LF、CRLF、CR，忽略空行和每行首尾空白；错误行号对应原始输入。所有输入通过验证后才展示结果，不输出部分排序列表。
- 修改输入或选项时清除旧结果与错误。校验失败聚焦输入并设置无障碍错误关联。复用 Workbench、Panel、Field、Textarea、Button 和 Output；复制失败仍可手动选择结果。
- 接入开发工具分类与搜索别名，沿用 Vite 页面发现、React Router、语言字典自动合并和共享 SEO 规则，无新依赖、外部服务或后端改动。
- 新增 `semver-additions` 全部 12 种语言的界面、校验错误与 SEO 文案。更新 README 和根目录工具计数：77 个工具（包含隐藏的翻译工具），948 个预渲染页面。

## 剩余限制与保留项

- 本机缺少 CJK 字体，中文截图显示方框；中文 DOM 文案、功能与 SEO 均检查通过，实际中文字形仍需在有 CJK 字体的浏览器中复核。未修改系统字体或配置。
- 不支持版本范围、不补全缺少的主/次/修订版本，也不接受大写 `V` 前缀；页面说明遵循严格 SemVer 版本格式。
- 构建保留既有 TOML `stream` 外部化、依赖 `eval`、英文字典静态/动态导入及较大分包提示，未改变检查要求。
- 纯前端新增工具，无需运行 Go 测试。全量前端测试包含既有网络回归检查；隐藏翻译菜单、仅 AliDNS 和网络修复保持原样。
- 仅修改当前 worktree 的工具源码、翻译、测试与文档；没有修改环境变量、密钥、部署配置、Tunnel、系统配置、主工作目录或自动任务脚本。未创建 Git 提交、推送或部署。
