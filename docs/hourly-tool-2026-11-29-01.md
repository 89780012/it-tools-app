## 工具与用途

- 名称：CSS 阴影生成器（CSS Box Shadow Generator）。
- 路由：`/tools/css-box-shadow-generator`；中文：`/zh/tools/css-box-shadow-generator`。
- 初始 worktree 干净，没有未完成的新工具。已阅读根目录及相关模块 CLAUDE.md、README.md、完整工具目录、最近八次 Git 更新、上一时段开发记录和 `docs/api-network-deployment.md`。现有 CSS 格式化、流体字号和贝塞尔曲线工具没有提供盒阴影设计功能；本次只新增这一个工具。
- 面向卡片、面板、按钮等界面的阴影设计。所有计算、预览、复制及下载均在浏览器内完成，不新增依赖、外部账号、API 或后台服务。

## 改动与行为

- `src/lib/box-shadow.ts`：纯函数验证并生成 CSS 声明和预览属性值。支持 1–8 层，保持输入层次顺序；支持内阴影、水平/垂直偏移、模糊半径、扩展半径、颜色和不透明度。
- 数字使用整数，偏移和扩展范围为 −500–500 px，模糊半径为 0–500 px，不透明度为 0–100%。接受首尾空白及负零；拒绝小数、单位、指数、非 ASCII 数字等输入。颜色仅接受六位十六进制 `#RRGGBB`，大小写均可，输出转为 rgba；拒绝 CSS 注入和其他颜色语法。
- `src/components/tools/css-box-shadow-generator.tsx`：复用 Workbench、Panel、Field、Input、Output 和错误组件。选择并编辑各层，添加或删除当前层；最后一层不可删除，达到八层不可继续添加。提供两层示例、清空、显式生成、可视预览、复制及 `box-shadow.css` 下载。
- 编辑字段、增加或删除层、加载示例、清空都会移除旧结果和复制反馈，同时移除旧预览。仅切换所编辑的层保留结果。校验失败时显示包含层号的本地化错误，切换到出错层，聚焦字段，并设置 aria-invalid / aria-describedby。清空回到单层空输入并聚焦水平偏移。
- 预览直接使用生成的 box-shadow；大阴影仅在预览区域被裁切，不影响输出。预览卡片使用现有主题颜色；下载只含 CSS 声明，不含卡片尺寸、背景、圆角等预览样式。
- 新页面沿用 Vite 模块发现和 React Router 机制。在 tools-config.ts 登记前端分类，并补充搜索别名和相关工具工作流。新增一组完整的 12 语言字典，包含名称、描述、SEO、全部界面文字及错误；自动接入现有字典合并、canonical、hreflang、预渲染和站点地图。
- README.md 和 CLAUDE.md 同步为 89 个工具（含隐藏项），12 种语言各 91 页，共 1092 页。
