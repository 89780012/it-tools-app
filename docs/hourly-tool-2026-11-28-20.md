## 工具与用途

- 名称：CSS clamp 生成器（CSS clamp Generator）。
- 路由：`/tools/css-clamp-generator`；中文：`/zh/tools/css-clamp-generator`。
- 开始时 worktree 干净，无未完成新增工具。阅读 CLAUDE.md、README.md、工具目录、最近 Git 更新及 18/19 时段记录后，确认现有 CSS 格式化器没有响应式字号生成功能；本次只新增这一工具。
- 输入两个视口宽度、对应的像素字号和根元素字号，生成可直接放入 CSS 规则的 `font-size: clamp(...);`。支持 px/rem 输出、递增、递减及恒定字号。
- 提供示例、清空、滑块模拟预览、复制与 `fluid-font-size.css` 下载。修改任一参数或输出单位，立即清除旧结果、复制反馈和错误。错误与输入关联并将焦点移至相应字段。

## 实现与边界

- `src/lib/css-clamp.ts` 为纯函数：计算线性插值的斜率和截距，按数值排序 clamp 上下限，因此反向字号也可正确钳制。
- 视口宽度为 1–100000 px 的整数，结束宽度必须大于起始宽度。字号为 0–10000 px，根元素字号为 1–1000 px；字号最多三位小数，使用十进制小数点。不接受空值、负数、指数、单位后缀、NaN、Infinity 或 CSS 注入文本。允许外部空白，单字段最多 32 个字符。
- 系数最多保留十位小数，去掉尾零，不输出科学计数法或负零。rem 声明在指定根元素字号下匹配输入的像素字号；实际根字号改变会改变 rem 上下限和截距，vw 则仍取决于视口宽度。页面明确说明此行为。
- 滑块模拟指定视口下的像素字号，使用原始插值参数；极大文字在固定高度预览框内裁切，不扩展页面宽度。预览与经过舍入的输出可能存在微小数值差异。
- 按 Vite 现有页面发现方式创建路由，复用 Workbench、Panel、Field、Input、Button 和 Output。登记前端分类、搜索别名与相关工具。
- 新增全部 12 种语言的界面、验证提示、工具名称/描述及 SEO 元数据。共享字典及 SEO 自动发现这些条目；不修改已有页面 SEO 规则。更新 README 和 CLAUDE.md 的工具数量为 84（含隐藏工具），预渲染页数为 1032。
- 没有新增依赖、API、账号或后台服务。
