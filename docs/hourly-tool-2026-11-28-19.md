## 规则与实现

- 空指针或 `#` 选择根值，`/` 选择空键；支持标量根值、对象、数组、空容器、false、0、空字符串和 null。
- 普通指针以 `/` 开始；URI 片段以 `#` 开始，先按 UTF-8 解码百分号编码，再分割路径，最后将 `~1` 解码为 `/`、`~0` 解码为 `~`。只解码一次，`~01` 表示字面键 `~1`。`+` 保持加号。
- 键名精确且区分大小写，不裁剪空白或执行 Unicode 规范化。数组索引从 0 开始，不接受前导零、负数、小数、指数和 `-`。对象上的 `01` 和 `-` 仍是合法键。
- 不执行表达式或脚本。只读取对象自身属性，`__proto__`、`constructor` 等作为普通 JSON 数据处理，不读取原型或无损数字包装对象的内部字段。
- 复用 `lossless-json` 保存整数、十进制、指数及负零的原始数值文本。选中的字符串保留 JSON 引号，下载内容可作为 JSON 再次解析。
- 拒绝整个文档中的重复对象键，包括值相同、转义后名称相同的重复键。依赖仅对值不同的重复键调用回调，因此在语法验证后增加按对象作用域检查键的扫描。
- 明确处理空文档、无效 JSON、无效 URI 编码、无效指针和转义、缺失键、数组越界、标量继续访问及资源上限。错误步骤从 1 开始。
- 限制：JSON 最多 500,000 个 UTF-16 单元，指针最多 4,096 个单元，JSON 嵌套最多 64 层，格式化结果最多 5,000,000 个单元。解析前检查深度，避免解析器处理过深输入。
- 复用 Workbench、Panel、Field、Input、Textarea、Button 和 Output。长文本框使用固定字段尺寸以支持滚动；保持移动端、深浅色主题和 RTL。
