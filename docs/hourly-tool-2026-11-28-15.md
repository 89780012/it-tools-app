## 工具与用途

- 英文路由：`/tools/ipv6-subnet-calculator`；中文路由：`/zh/tools/ipv6-subnet-calculator`。
- 开始时 worktree 干净。已阅读根目录及相关模块的 CLAUDE.md、README、工具目录、近期 Git 更新、上一时段工具记录和 `docs/api-network-deployment.md`。现有子网计算器仅支持 IPv4，本时段仅新增 IPv6 子网计算器。
- 用于 IPv6 地址规划、核对子网边界和地址数量。输入带前缀的地址，提供计算、示例、清空、结果展示、复制及 `ipv6-subnet.txt` 下载；修改输入立即清除旧结果及错误。

## 实现与规则

- `src/lib/ipv6-subnet.ts` 使用 BigInt 完成全部 128 位运算。支持 `/0` 到 `/128`，精确输出地址总数、网络 CIDR、首末地址、完整掩码、前缀与主机位数、地址偏移及压缩和展开形式。
- 接受大小写十六进制、`::` 压缩及点分 IPv4 尾部；输出使用小写十六进制，去除组内前导零，并压缩首个最长且至少含两个零组的连续段。IPv4 尾部统一转成十六进制。
- IPv6 不存在广播地址。总数包含整个范围，不扣除保留地址，也不推测可用主机数；地址偏移从零开始。页面明确说明这些含义。
- 输入最多 256 个 UTF-16 代码单元；允许整体首尾空白，不允许地址内部空白。必须包含一个斜杠，前缀为无前导零的十进制整数。不接受裸 IPv4、方括号、区域 ID、无前缀的地址；不解析 URL 或独立端口字段。
- 对分组数量、多个双冒号、压缩未省略任何组、超长组、非十六进制字符、IPv4 尾部的范围与前导零、非法前缀和输入长度提供本地化错误。错误关联 `aria-invalid`、`aria-describedby` 与 alert，并聚焦输入。
- 复用 Workbench、Panel、Field、Input、Button、Output 及现有复制失败反馈；遵循 Vite 页面发现和 React Router 路由。
- 登记工具目录、搜索别名及相关工具。新增全部 12 种语言的名称、描述、界面、错误与 SEO 文案，复用共享 SEO 规则和字典自动合并。README 与架构文档更新为 79 个工具（含隐藏的翻译工具）、972 个预渲染页面。
- 无新增 npm 依赖、外部 API 或后端服务。
