# 日期间隔计算器（2026-11-28）

## 工具与使用场景

- 英文路由：`/tools/date-duration-calculator`；中文路由：`/zh/tools/date-duration-calculator`。
- 开始时 worktree 干净，没有未完成的新增工具。阅读项目规范、工具目录、最近 Git 记录和前两天的开发记录后，确认现有时间转换器和 Cron 工具没有提供日期间隔与工作日计算，本次只增加这一项工具。
- 用于排期、假期及日期跨度核对。输入开始日期、结束日期，可选择是否包含结束日期，并按行输入自定义节假日。
- 展示日历天数、完整周与余天、扣除节假日前的平日天数、周末天数、实际扣除的节假日数量和工作日。提供示例、清空、复制与 `date-duration.txt` 下载。
- 示例为 2026-11-23 至 2026-11-30，排除结束日期、扣除 2026-11-26，结果为 7 个日历日、4 个工作日；包含结束日期时为 8 个日历日、5 个工作日。

## 实现与规则

- `src/lib/date-duration.ts` 严格解析 `YYYY-MM-DD` 公历日期，支持 0001–9999 年，拒绝不存在的日期、年份 0000 和反向区间。以 UTC 日期索引进行整数天运算，不使用本地时刻，不受夏令时影响，也避免 JavaScript 把两位年份映射到 1900 年代的问题。
- 默认区间为 `[开始日期, 结束日期)`，相同日期得到 0 天。勾选包含结束日期后计入两端，相同日期得到 1 天。
- 工作日定义为周一至周五，扣除所填节假日。对重复节假日去重；周末及区间外的日期不扣除。所有节假日都先校验，错误提示保留原始行号（含空行）。
- 节假日最多 10,000 个物理行、120,000 个 UTF-16 字符，支持 LF、CRLF、CR 和空行。工作日按整周加不足一周的余天计算，无需逐日遍历数千年区间。
- 输入错误会标记并聚焦对应字段；修改日期、节假日或选项立即清除旧结果和错误。复制失败时保留可选择的结果并显示提示。
- 复用 Workbench、Panel、Field、Input、Textarea、Button 和 Output。沿用现有 Vite 页面收集、React Router、语言字典合并、客户端 SEO 与构建预渲染机制，没有新增依赖或后端。
- 更新 `tools-config.ts` 时间分类、搜索别名、相关工具推荐，以及 `date-duration-additions` 全部 12 种语言的界面、错误和 SEO 文案。README 与根目录规范同步工具及页面计数：76 个工具（含隐藏翻译工具）、936 个 SEO 页面。

## 剩余限制与保留项

- 不自动加载各国法定节假日，不处理周末调休上班；页面已明确说明。按小时、时区或自然月的间隔不属于此工具的计算范围。
- 中文实际字形仍需在具备 CJK 字体的浏览器中复核，未修改系统字体或配置。
