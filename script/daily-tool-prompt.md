你在 IT Tools 项目的独立 Git worktree 中执行每日开发任务。

目标：新增一个实用、完整、与现有目录不重复的工具。

1. 先阅读 CLAUDE.md、README.md、工具目录和最近更新记录，选择一个当前缺少的工具。若工作目录已有未完成的新增工具，继续完成它，不再选择第二个。优先纯前端实现，例如开发、文本、数据转换、日期或图像工具，不增加付费 API、外部服务账号或新后台服务依赖。
2. 每次只新增一个工具。为真实使用场景完成输入、处理、结果展示、复制或下载、清空、示例和错误处理；不要添加占位页面。
3. 遵循 React/Vite 项目现有组件和路由方式，更新 src/lib/tools-config.ts、必要的 SEO 信息和全部 12 种语言。复用现有依赖，保持移动端和深浅色主题可用。
4. 检查 docs/api-network-deployment.md。保留已隐藏的翻译菜单、仅 AliDNS 的服务商配置及现有网络修复，不重新启用未配置的服务。
5. 为新增工具的核心行为补充有意义的测试，覆盖有效输入、错误输入及关键边界；运行适用的前端测试和生产构建。通过浏览器检查新页面交互，记录检查结果。Go 测试需要时可使用项目文档中的 Docker 方式。
6. 只修改此 worktree 内与工具实现有关的源代码、翻译、测试和文档。不修改 .env、主工作目录、系统配置、Tunnel、定时器、每日任务脚本、密钥或部署配置。不删除旧工具，不发送消息给他人。
7. 不创建 Git 提交、不推送、不部署，这些由外层脚本在验证后统一执行。不要为了通过检查而删除测试、降低检查要求或伪造结果。
8. 最终用中文说明：新增工具名称和路由、用途、改动、已运行的检查及结果、剩余问题。如果无法完成，明确说明，不宣称成功。
